# AsylDreams — портфолио

Сайт-портфолио AI-художника AsylDreams: ночные 4K-обои, кинокадры и портретные серии.
Живёт на GitHub Pages: https://dousheng34.github.io/asyldreams-portfolio/

## Стек

- **Vite 7 + React 19 + TypeScript** — статический билд, никакого бэкенда
- **Tailwind CSS 4** — токены темы в `src/styles/index.css`
- **GSAP 3.13** (ScrollTrigger, SplitText) — все сценарные анимации
- **Lenis** — плавный скролл, синхронизирован с тикером GSAP
- **OGL** — WebGL-портал в hero: кроссфейд кадров через шумовую маску + искажение от курсора
- Шрифты: Unbounded / Inter Tight / Cormorant Garamond (все с кириллицей)

## Что внутри

| Блок | Приём |
|---|---|
| Прелоадер | счётчик привязан к реальной загрузке hero-кадров, шторка уходит clip-path |
| Hero | посимвольный SplitText, WebGL-слайдшоу, параллакс при скролле |
| Работы | журнальная 12-колоночная сетка, clip-path reveal, параллакс внутри рамок |
| Серии | pinned-секция с горизонтальной лентой (desktop), вертикально на мобильных |
| Манифест | слова проявляются по скроллу (scrub) |
| Обо мне | счётчики цифр, 3D-tilt карточки за курсором |
| Услуги | превью кадра следует за курсором |
| Заказ | форма собирает бриф и копирует его в буфер |
| Лайтбокс | клавиатура ← → Esc, свайпы, направление смены кадра |

Кастомный курсор, плёночное зерно, `prefers-reduced-motion` — всё учтено.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/
npm run preview
```

## Как править контент

Все тексты, серии и работы — в одном файле `src/data/portfolio.ts`.

- **Добавить работу**: положи `.webp` в `public/art/`, добавь запись в `works` (ключ, название, размеры, цвет, `src`, `srcset`, `lqip`), затем укажи ключ в нужной серии в `series`.
- **Избранное на главной** — массив `featured`; **кадры в hero** — `heroKeys`.
- **Цифры и услуги** — объект `profile`.

`lqip` — крошечная 16px-заглушка в base64 (можно сгенерировать любым способом или оставить пустой строкой).

## Деплой

Пуш в `main` → GitHub Actions собирает проект и публикует на Pages (`.github/workflows/deploy.yml`).
В настройках репозитория `Settings → Pages → Source` должно стоять **GitHub Actions**.
Для своего домена задай `VITE_BASE=/` при сборке.
